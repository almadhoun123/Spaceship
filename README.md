# Spaceship

A space ship rail shooter by NeoArt. Made with Unity 6000.3.27f2 (URP) and Blender.

## Folders

| Folder | What is inside |
|---|---|
| `Assets/`, `Packages/`, `ProjectSettings/` | The Unity project |
| `blender/` | Blender files for ships and other 3D assets |
| `blender/scripts/` | Scripts that build the assets |
| `blender/renders/` | Review pictures and videos |
| `blender/textures/` | Source textures |
| `audio/` | Sound scripts and previews |
| `docs/` | Design documents and reference images |

## Git

- Large files (.blend, .fbx, images, audio, video) use Git LFS. Run `git lfs install` once after cloning.
- Each team member works on their own branch.
